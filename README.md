# LabMate

MVP-сервис для поиска помощи с учебными задачами.

## Запуск

```bash
npm install
npm run dev:full
```

Клиент откроется на `http://localhost:5173`, API работает на `http://localhost:3001`. SQLite-файл `labmate.sqlite` создаётся автоматически в корне проекта.

SQLite работает через `sql.js` (WebAssembly), поэтому для установки зависимостей не нужны Visual Studio, MSVC, Windows SDK или Python.

В MVP доступны:

- регистрация и вход по email/паролю;
- режимы студента и помощника;
- создание, просмотр и удаление задач с полями названия, предмета, темы, задания, комментария и цены;
- автодополнение предметов и тем с добавлением новых значений в каталог;
- лента задач с фильтрами;
- отклики помощников и переписка через HTTP;
- выбор помощника студентом и ограничение доступа к выбранному чату.

Email-подтверждение, платежи, загрузка файлов и WebSocket-чат намеренно не входят в MVP.
